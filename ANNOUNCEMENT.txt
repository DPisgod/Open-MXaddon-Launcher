Open-MXaddon-Launcher 1.3.6 更新公告

【Java 切换与自动选择】
设置的 Java 路径旁新增“切换 Java”，后台检测本机常见安装位置、环境变量与实例运行时，显示版本号、架构和路径，支持手动浏览及重新检测。列表第一项为“自动选择”，选择后清除手动路径；自动模式优先使用游戏实例自带的 Java，再匹配本机相同主版本的运行时。选择后点击设置中的“保存”生效。

【下载页底部按钮位置调整】
将社区资源下载页底部的两组控件左右调换：“导入整合包、上一页、下一页、返回版本”移至左侧，“包含 Beta / Alpha、自动下载必需依赖”移至右侧。各组内部顺序和操作功能保持原样。

【六种风格平铺选择】
个性化中的界面风格改为两行三列平铺，点击名称前的圆点即可选择，立即应用并保存。保留浅色、深色、霓虹赛博，新增中国红、樱花粉、基佬紫。中国红采用红金暖色，樱花粉采用粉白配色，基佬紫采用深紫配色；背景、文字和控件统一随风格变化，继续使用柔和圆角布局。重启后保留已选风格。

【UI 透明度实时预览】
在个性化中拖动 UI 透明度滑块时，顶栏和启动栏背景会跟随鼠标同步变化，无需松手才看到效果。松开鼠标后保存最终数值，拖动期间不反复写入配置；保存失败时恢复原值。浅色、深色和霓虹赛博三种风格均支持，壁纸设置保持独立。

【沿用上一版改进】

【设置窗口恢复正常】
修复部分分发包中点击右上角设置没有弹出窗口的问题。自带 Java 现已补齐内存检测模块，并加入打包校验；设置中的自动内存、自定义内存及保存操作恢复正常。

【刷新时保持原有配色】
修复下载中心在刷新、搜索或读取文件时，部分筛选框与输入框临时变成白色的问题。浅色、深色和霓虹赛博风格在加载期间均保持原有背景，操作完成后正常恢复。

【更流畅的进度条】
进度条改用约 60 次/秒的重绘节奏，确定进度加入平滑过渡，等待状态保持连续运动。动画只影响显示，不改变实际下载和安装进度；隐藏或最小化后停止不必要的重绘。

【页面和窗口过渡动画】
主页、个性化、壁纸、下载中心、下载分类和版本设置标签加入短暂的淡入与轻微横移。启动器窗口、设置和安装等对话框、账号弹出菜单加入内容淡入与轻微上移，保留现有柔和圆角布局。

【滑块直接定位鼠标】
透明度、模糊、遮罩、内存等调节滑块，点击轨道即可直接跳到鼠标位置，按住后可继续拖动，不再只移动一小段。原来的数值范围和键盘调节方式继续保留。

本版沿用已确认的动画预览效果。升级保留游戏、存档、账号、壁纸和个性化设置。
