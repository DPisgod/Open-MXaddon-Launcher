Open-MXaddon-Launcher 1.2.0 更新公告

【全新的下载中心】
下载页面现在直接融入主界面。顶部分类导航集中提供游戏版本、Mod、整合包、数据包、资源包和光影包；资源结果与详情并排展示，查找、筛选和安装更方便。

【游戏版本与加载器】
新增最新正式版、最新预览版快捷卡片，显示发布时间；支持正式版、预览版、远古版（含 Beta / Alpha）、愚人节版本分类和版本号搜索。
选择游戏后会自动检测 Fabric、Quilt、Forge、NeoForge 的兼容版本，可以选择加载器测试版，继续支持自动下载匹配 Java、Fabric API 和手动保存加载器。

【社区资源】
支持全部来源、Modrinth、CurseForge，提供类型标签、排序和一键重置。列表展示资源简介、下载量、更新时间和图标，选中后查看兼容文件，可下载并安装，也可仅保存文件。
CurseForge 仍需要官方 API Key；未配置时全部来源会提示并展示 Modrinth。

【数据包】
新增数据包搜索与下载。安装时需选择具体存档，文件会放入该世界的 datapacks 目录。兼有模组与数据包的项目会筛选数据包 ZIP，避免误装模组 JAR。

【OptiFine】
提供官网获取与本地 JAR 安装入口。请从官网下载匹配的安装包，选择后由启动器在独立实例内完成安装。当前本地 OptiFine 独立安装与其他模组加载器互斥。

本次升级保留游戏、存档、账号、壁纸与现有设置。祝你游戏愉快！
