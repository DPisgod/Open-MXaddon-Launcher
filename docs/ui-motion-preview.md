# 1.3.2 动画与交互

本版将用户已确认的本地预览效果正式发布。界面形状和布局继续沿用柔和圆角。

- 修复刷新/搜索禁用筛选框时的白底：`BasicComboBoxUI` 的默认禁用绘制会覆盖 renderer 配色，因此统一绘制当前值和背景，编辑框也保留主题背景与禁用文字颜色。
- 滑块点击轨道直接映射到鼠标坐标，支持继续拖动；抓住已有滑块时保留抓取偏移。沿用原来的数值范围、键盘操作、反向与 RTL 支持。
- 进度条使用独立 16 ms 定时器，确定进度平滑逼近真实模型数值，未确定进度保持连续运动。隐藏、移除或窗口最小化时停止。
- 页面切换采用 220 ms 的三次缓出、淡入与约 14 px 的轻微横移；快速切换从当前画面继续，结束后释放快照。覆盖主导航、个性化壁纸子页、下载分类和版本设置标签。
- 主窗口、启动器对话框和账号弹出菜单采用约 190 ms 的内容淡入和 10 px 的上移。窗口本身保持不透明，不改变原生窗口大小或使用分层窗口透明度，保留正常截图与最大化行为。

Windows 默认定时精度会使 16 ms Swing 定时器降到约 30 次/秒。仅在动画或可见进度条运行时成对申请/释放高精度定时，遵循 [Microsoft timeBeginPeriod 文档](https://learn.microsoft.com/en-us/windows/win32/api/timeapi/nf-timeapi-timebeginperiod) 的生命周期要求。实测 100% 与 125% 缩放下约 60 次重绘/秒；实际表现仍取决于绘制负载。

`MotionAndControlsTest` 使用真实资源页任务状态与临时数据，验证浅色、深色、霓虹赛博在禁用/恢复时背景不变，覆盖编辑框、滑块直接定位与继续拖动、反向/RTL、确定进度平滑且不修改模型值、进度隐藏后停止、快速页面切换释放快照、窗口内容入场、普通不透明 HWND 以及高精度定时请求释放。

`MotionPreview` 从生产界面录制 60 fps 的离线演示视频，只用临时目录和示例版本，不包含用户账号、存档或真实下载。预览包默认霓虹赛博，可自行在个性化中切换。
