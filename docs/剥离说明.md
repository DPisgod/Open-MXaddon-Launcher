# 剥离说明：去掉云载 DLL 注入后保留了什么

本版在原工程（MxAddon / MXCloud 启动器）基础上，删除了「云端下发加密 mod 包 +
运行时注入」这条链路，只保留启动器本身的功能：安装游戏版本、管理账号与 Mod、
**启动游戏**。

## 一、删除的原生层与注入链路

| 原路径 | 作用 | 处理 |
|---|---|---|
| `launcher-rust/` | Rust 原生层：`auth.dll`（HWID/授权）、`core.dll`（云载下载 → 解密 → 注入启动）、`host/` C++ 宿主、`build_*.ps1` | 整目录删除 |
| `launcher-java/bootstrap/` | `BootstrapMain`：接收匿名管道密钥 → 解密云载密文 → 写入临时 JAR → 用 `fabric.addMods` 注入后反射调用 `KnotClient` | 整目录删除 |
| `launcher-java/src/main/java/.../MxCloudNative.java` | JNA 绑定 `auth.dll` / `core.dll`（`c_launch` / `c_is_valid` / 下载进度 / 停止） | 删除 |
| `IsolatedCaller.java`、`WorkerMain.java` | 隔离子进程调用 DLL（防 Rust panic 拖死 GUI） | 删除 |
| `ProductAuth.java`、`ProductLoginDialog.java`、`ActivateDialog.java`、`ActivationStore.java`、`LicenseStatus.java`、`LicenseCheckDialog.java` | 官网账号登录、卡密激活、授权状态与到期提示 | 删除 |
| `UpdateGate.java`、`LauncherUpdates.java` | 强制在线版本校验与在线自更新 | 删除 |
| `ServerConfig.java`、`LoginDiag.java`、`LoginProbe.java` | 自有服务端地址与登录诊断上报 | 删除 |
| `SmokeTest.java`、`ShotTool.java`、`ActivateShot.java`、`LoginShot.java` | 依赖上述 DLL/授权链的调试入口 | 删除 |
| 对应测试（`ActivationTest`、`LicenseStatusTest`、`LicenseCheckDialogTest`、`LauncherUpdateTest`、`UpdateGateCloseTest`、`LoginDialogVisualTest`、`PrepareLiveLauncherSession`、`BootstrapPipeTest`） | 已被测对象不存在 | 删除 |
| `build-integration.ps1`、`publish-launcher.ps1`、`一键打包发布.cmd`、`build-server-release.ps1`、`tools/release/`、`.github/workflows/` | 云载/更新包的发布流水线 | 删除 |
| `launcher-java/build.bat`、`package.bat`、`package.ps1`（旧） | 从 `mxcloud-client/dist` 拷贝 DLL 的旧打包脚本 | 删除，改为 `launcher-java/build.ps1` |
| `CONFIG.example.md`、`docs/three-stage-auth.md`、`docs/launcher-updates.md`、`docs/license-expiry-cache.md`、`docs/portal-security-hardening.md`、`docs/one-click-release.md`、`docs/admin-card-dialog.md`、`docs/launcher-versions.md` | 描述已删除的授权/云载/发布功能 | 删除 |

`website/`、`server-backend/`、`mod-auth/` 保留原样，它们属于原有后端与 mod 侧代码，
与本启动器无调用关系，本版未使用。

## 二、新增/改写

| 文件 | 说明 |
|---|---|
| `launcher-java/.../GameLauncher.java` | **新增**。纯 Java 启动：读 `versions/<版本>/<版本>.json` → 组装 classpath（版本 jar + 清单内 Windows 依赖）→ 原生库（`<版本>-natives`，缺失则从 `natives-windows` 依赖包解出 DLL）→ 拼 `java` 参数（内存/G1/编码/`-Djava.library.path`/账号参数）→ 启动进程并写 `logs/launcher-game.log` |
| `LauncherFrame.java` | 启动流程改为直接调用 `GameLauncher`；移除授权校验、云载下载进度、DLL 就绪等待 |
| `Main.java` | 去掉启动前的强制更新校验，直接进入主页 |
| `VersionInstaller.java` | 安装内容改为「原版 1.21.1 + Fabric 加载器 + 资源」，不再自动装 Fabric API / Kotlin 两个 mod；`mods` 目录留空 |
| `Http.java` | User-Agent 不再依赖已删除的 `ServerConfig` |
| `launcher-java/build.ps1` | 新打包脚本：javac → 带资源的 jar → jlink 自带 JRE → 调用 `shell/build_shell.ps1` 出自解压 exe |
| `build-all.ps1` / `一键构建.cmd` | 根目录一键构建：启动器 + 单文件 exe + NSIS 安装包 |
| `launcher-java/shell/MXCloudLauncher.cpp`、`build_shell.ps1` | 自解压壳去掉 `Libraries/auth.dll`、`core.dll` 校验，只释放 jar + JNA + JRE |
| `installer/MXCloud.nsi`、`build-installer.ps1`、`build-inspector.ps1`、`inspect-install.cpp` | 卸载不再清理云载缓存；卸载程序改名为 `卸载 MXCloud.exe`；检查器脚本改为在纯 ASCII 临时目录编译（兼容含中文的工程路径） |

## 三、行为差异

| 项目 | 原版 | 本版 |
|---|---|---|
| 启动游戏 | `core.dll` 云载下载 → 解密 → 管道传钥 → `BootstrapMain` 注入 mod → `KnotClient` | 直接 `java -cp ... <mainClass>` 启动，注入链路完全不存在 |
| 联网校验 | 每次启动在线校验授权、票据一次性核销 | 无，纯本地 |
| mod 来源 | 服务端按 HWID 加密下发，磁盘不落明文 | 仅 `mods` 目录中的本地文件 |
| 更新 | 强制在线版本校验，版本不符即退出 | 无强制更新 |
| Java | 需要匹配的 DLL | 自带 JRE 21（`runtime`），优先使用 |
