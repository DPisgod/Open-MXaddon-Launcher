Open-MXaddon-Launcher 使用说明

1. 运行“OML启动器.exe”打开启动器。安装包首次默认位置为 D:\Open-MXaddon-Launcher，升级会沿用原安装目录。
2. 顶部“下载”打开下载中心。游戏版本页提供最新正式版/预览版，以及正式、预览、远古（Beta / Alpha）、愚人节分类；输入版本号可筛选列表。
3. 选中游戏后点击“配置并安装”，选择原版、Fabric、Quilt、Forge 或 NeoForge。加载器卡片显示兼容状态，可选择具体版本和测试版；支持自动下载游戏 Java、Fabric API，以及仅保存加载器文件。
4. OptiFine 请先通过配置页的官网入口获取安装 JAR，再选择“本地 JAR”。启动器核对 Minecraft 版本后在独立实例安装；当前独立 OptiFine 与其他加载器互斥，不要同时选择。
5. Mod、整合包、数据包、资源包和光影包可在下载中心顶部切换。支持来源、类型标签、Minecraft 版本、加载器、排序和重置条件；点击资源可查看兼容文件，支持 Beta / Alpha。
6. Modrinth 无需密钥。CurseForge 需要官方 API Key，在“CurseForge 密钥”中配置，使用 Windows DPAPI 加密保存在本机。未配置时“全部来源”会提示并展示 Modrinth。
7. “下载并安装”需要选择目标实例；整合包会创建新实例。数据包还需选择具体存档，ZIP 会安装到该世界的 datapacks 文件夹。没有存档时请先创建世界，或选择“仅下载文件”。光影仍需游戏内的 Iris / OptiFine 等渲染支持。
8. 在主页选择已安装版本和账号，然后点击“启动游戏”。头像/名字入口可添加、切换、删除正版或离线账号。正版通过微软设备码登录；离线账号无需联网，离线名称支持 1–16 个中文、英文、数字或下划线。
9. 游戏独立目录为 .minecraft/versions/<实例名称>/instance，存档、配置和 Mod 位于其中。已有实例不会被安装任务覆盖；旧 .min 和根目录设置会在首次启动时自动迁移。
10. “当前版本设置…”可管理 Mod 和游戏参数；也可拖入 JAR 添加 Mod。禁用会改为 .jar.disabled，卸载移入 mods/.mx-trash。删除游戏版本移入 .minecraft/.mx-version-trash，可手动找回。
11. 全局及版本设置支持自动或自定义内存。可多开游戏；主页圆形电源按钮会结束本启动器打开的全部游戏客户端，未保存进度可能丢失。修改资源前请先退出游戏。
12. “壁纸”内置 Windows10、红色力量、水灵灵、线条风、刀客、动漫女孩。Windows10 为默认壁纸。可自行导入图片或视频，预览后点击“应用壁纸”；支持循环、静音、模糊和遮罩。自定义文件复制到启动器旁 wallpapers，原文件移动后仍可使用。
13. 顶部“个性化”集中提供界面风格、UI 透明度与壁纸设置。风格以浅色、深色、霓虹赛博、中国红、樱花粉、基佬紫六个名称平铺显示，点击名称前的圆点选择，切换后立即保存；所有风格均使用柔和圆角的同款布局与组件，只改变颜色和外观。壁纸选择和播放设置通过个性化内的入口打开。动态壁纸和播放器均随包内置；最小化、打开个性化、壁纸或下载页时暂停主页播放，也可设置游戏启动后暂停。
14. 每次启动后台检查 GitHub 最新正式 Release，可取消或立即更新。安装更新保留游戏、存档、账号、壁纸和设置；下载中可取消。公告从仓库 ANNOUNCEMENT.txt 读取，可拖动和关闭，内容变化后重新显示。
15. .minecraft 保存账号、设置、游戏及下载缓存；缓存 .mx-downloads 可在没有任务时删除。账号凭据不上传到仓库。导入的皮肤和壁纸分别保存在启动器旁 skins、wallpapers。
16. 窗口顶部可拖动，边缘可缩放；右上角提供最小化、最大化/还原、关闭。重复打开启动器会唤起已有窗口。关闭启动器不会结束已经启动的游戏。
17. 安装包支持更新、修复和同版本重装。卸载会永久删除整个安装目录（包括游戏、存档、账号和壁纸）及运行时缓存，请先退出启动器与游戏并备份需要保留的文件。

18. 下载中心刷新、搜索和读取文件期间，临时禁用的筛选框保持当前主题背景。调节滑块点击轨道可直接定位到鼠标，按住可继续拖动。
19. 进度条采用约 60 次/秒的动画重绘，并平滑显示确定进度。页面切换约 220 毫秒、窗口入场约 190 毫秒；隐藏或最小化后停止不必要的动画，实际效果取决于机器负载。
20. 个性化中的 UI 透明度滑块在拖动时实时预览顶栏和启动栏背景，松开鼠标后保存最终数值；保存失败会恢复原值，不影响壁纸设置。
21. 设置中的 Java 路径旁可点击“切换 Java”，查看本机检测到的版本、架构和路径。列表第一项“自动选择”会清空手动路径，优先使用实例自带运行时，再匹配本机相同主版本的 Java；选择后点击设置中的“保存”生效。也可重新检测或手动浏览 Java 文件。
22. 添加版本的安装窗口默认 820×360，显示在主页中部稍靠上，保留顶部导航和底部启动区域。安装配置可在中间滚动查看，进度、关闭和安装按钮固定在下方。
