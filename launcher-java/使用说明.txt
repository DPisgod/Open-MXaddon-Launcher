MXCloud 启动器 使用说明

1. 启动器只做两件事：安装游戏版本、启动游戏。不联网校验账号，不需要卡密激活。
2. 展开主页版本列表，选择“添加版本…”并点击“一键安装”，自动下载 Minecraft 1.21.1、Fabric 加载器与完整资源文件。已有版本不会被自动删改。
3. 点击左下角头像或名字，可添加、快捷切换或删除 Minecraft 正版/离线账号。添加正版账号时自动复制微软验证码并打开浏览器；离线账号无需联网。
4. 版本列表的“当前版本设置…”可打开 Mod 管理：添加、定位、启用/禁用、卸载；也可把 JAR 直接拖到主页添加到当前版本。mods 目录默认为空，不预装任何 Mod。
5. 禁用仅将 .jar 改为 .jar.disabled；卸载移入该版本 mods/.mx-trash，可手动找回。游戏运行时请先退出再修改 Mod。
6. 新安装版本的独立游戏目录为 .minecraft/versions/1.21.1-MXCloud/instance，存档、配置与 Mod 均在其中。
7. “壁纸”中导入 JPG、PNG、WebP、GIF、MP4 或 WebM；支持拖放、预览、循环、静音、模糊、遮罩和 UI 透明度调节。视频按原片时间戳播放。
8. 浅色、深色和跟随系统可在顶栏切换。导入文件复制到启动器旁 wallpapers 目录，原文件移动后仍可使用。
9. 动态壁纸默认静音，最小化时暂停；可选择在游戏启动后暂停，节省资源。
10. 离线名字支持 1–16 个中文、英文、数字或下划线。账号列表中可导入离线账号的 PNG 皮肤大头；正版头像按官方皮肤获取，可刷新。
11. 版本列表的“删除当前版本…”会将整个版本文件夹移入 .minecraft/.mx-version-trash，可手动找回。独立实例中的存档、Mod 和配置一起保留；公共依赖不删除。
12. 窗口按钮已内置到页面：主页右上角可最小化、最大化/还原和关闭；拖动顶部空白或标题移动窗口，边缘调整大小。功能窗口右上角关闭，Esc 也可关闭。
13. 每次启动完成后可继续点击“启动游戏”多开。上方圆形电源按钮会直接结束本启动器打开的所有游戏客户端，悬停可查看数量；未保存的游戏进度可能丢失。
14. 全局设置的内存分配支持自动/自定义；“当前版本设置…”的“游戏设置”页支持跟随全局、自动或自定义。保存后下次启动生效，多开时自动模式会重新计算。
15. accounts.dat、session.properties、launcher.properties、appearance.properties 统一保存在 .minecraft 中；旧版根目录文件会自动迁移。skins 和 wallpapers 位置保持不变。
16. .minecraft/.mx-downloads 是一键安装的下载缓存，供重试/重装复用。没有安装任务时可以删除，已安装游戏不受影响。
17. 最大化采用屏幕工作区尺寸调整并保留还原位置；启动器使用 GDI 兼容绘制，关闭 Direct3D/OpenGL 路径，仅作用于启动器。错误日志在 .minecraft/logs/launcher.log，游戏日志在版本目录的 logs/launcher-game.log。
18. 一键安装遇到连接或读取超时会自动重试，单个文件最多尝试 3 次。仍失败时显示下载域名和文件名，详细错误写入 .minecraft/logs/launcher.log。点击“重试安装”会复用已通过校验的缓存。
19. 启动游戏使用启动器自带的 Java 运行时（runtime 目录），不需要另外安装 Java；如缺少则回退到系统的 JAVA_HOME / javaw。
20. 启动器为单实例，重复打开会唤起原窗口。游戏与启动器进程互相独立，关闭启动器不会结束游戏。
21. 卸载会永久删除整个安装目录（含游戏、存档、账号和壁纸），并清空启动器运行时缓存；请先关闭启动器和游戏，备份需要保留的文件。
22. 安装包会扫描已有程序完整性和版本，分别提示更新、同版本重装或修复；未安装时进入新安装流程。启动器版本可在设置页查看，与安装包及 EXE 属性保持一致。
